# Fixture set `slice1-synthetic`

Synthetic data for development and test only (W0-08 section 8; W0-02 section 8.3). Everything here is invented inside this repository: no name, address, identifier, document or sentence is copied from any real review case, from the source-system evidence the product documentation cites, or from any real document. Addresses use the reserved domain `rai-desk.example`; registry ids use the reserved year `RAI-2000-nnnn`; source record ids are `AIR-FX-nnnn` or the literal `Unknown`; business units `CM` and `HR` are labels. `provenance.test.ts` greps every file here and every generated byte against a pattern denylist on each run; a human reviewer confirms the rest at the W1-09 review.

No document bytes are committed. `npm run fixtures:generate` writes them to `rai-web/.local/fixtures/<fixture id>/<filename>` (gitignored) from Node built-ins; `npm run fixtures:load` generates them when absent, stores each under `BLOB_DIR/sha256/` and writes the rows.

## Identity: how evidence cites the set

Every evidence record cites the string `fixtures:generate` and `fixtures:load` print, `fixture set slice1-synthetic@<version> <sha256[0:12]>`, next to the command output. The hash covers the files in this directory (except `manifest.json` and tests) and every document digest, so any change to a user, case, document row, README or generator output changes it; the same PR bumps `version` and runs `npm run fixtures:generate -- --write-manifest`. `fixtures:load` writes the name, version and hash into the `fixture_set` table so a database can be checked against the record.

The loader never inserts a submitted version, a lane decision, a finding, a disposition or an audit event for these rows: journeys produce that state through the real transitions (W0-08 8.1 rule 4, A11).

## What every generated document contains

The sentinel `RAI-DESK-SYNTHETIC-FIXTURE`, its fixture id, its case id, its slot number and name, the Thai line `เอกสารสังเคราะห์สำหรับการทดสอบ ไม่ใช่เอกสารจริง` and the sentence `Generated by rai-web/fixtures. Not a real document. Contains no real data.` Nothing else. Document-quality defects for the QC substitute (W1-10) are scripted against the fixture artifact id, not encoded in the bytes.

## Changing the set

Edit the tables, run `npm run fixtures:generate -- --write-manifest`, bump `version` in `manifest.json`, update W0-08 sections 8.3 and 8.4 in the same PR, and keep old evidence citing the old version. Never add a committed binary, a real name or an address outside `rai-desk.example`.

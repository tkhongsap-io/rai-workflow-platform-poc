## Deviations, defaults and limitations (for the reviewer)

- **Blob writes go through `fixtures/src/generate/blob-layout.ts`, not W1-03a's `BlobStore`.** W0-08 8.7 says the loader stores objects "through the same blob interface uploads use"; that interface (`server/src/artifacts/`, Lane A) does not exist yet and this ticket must not create it. The loader writes the exact W0-04 layout (key path, modes, temp-then-rename, dedupe with size check) so W1-03a finds the objects where its `put` would have placed them; W1-03a replaces the call with `blobStore.put` in its PR (one call site).
- **`reset` order changed** (root `package.json`): `db:down`, remove `.local`, `db:up`, `migrate`, `fixtures:load`. The W1-00 order removed `.local` after `fixtures:load`, which deleted the objects the loader had just written and left artifact rows pointing at nothing. The command name and its parts are unchanged; the W0-02/W0-08 prose ("recreates the database, migrates, loads the fixtures and empties `rai-web/.local`") lists the parts, not a sequence.
- **New table `fixture_set` and migration `0001`** in Lane A paths (`server/src/db/schema/`, `server/drizzle/`). W0-08 8.7 and the W1-00 review assign "the `fixture_set` row" to W1-09, and a row needs a table; W0-04 does not define one, so the shape here is the minimum (name, version, sha256, loaded_at, correlation_id; PK on name and version; `rai_app` SELECT/INSERT). The W1-00 migration test's exact table and grant lists gained the two entries; `tests/support/db.ts` truncates it.
- **`loadFixtures` signature** now needs `identityMode` and `blobDir` (W0-08 8.1 rule 5 and 8.7); the one W1-00 call site (`w1-00-configuration.test.ts`) passes them with a temp `BLOB_DIR`.
- **No audit events for fixture rows.** The seed's `configuration.published` events remain (W1-00); the cases, drafts, slots and artifacts are inserted without `case.created`, `draft.saved` or `artifact.uploaded` events, because those would be a fabricated trail of actions that never ran through the routes (W0-08 8.1 rule 4, A11). Journeys that need a trail create it through the real transitions.
- **PNG size**: W0-08 8.4 marks the small class "< 10 KiB"; a 64 × 64 RGB PNG with a stored IDAT (8.5's rule) is 12.5 KiB by arithmetic, so the two PNGs are bounded at 16 KiB in the test and every other small document at 10 KiB. No spec text was edited.
- **The sniff used by the generator test is test-local** (`generate.test.ts`), mirroring W0-08 section 2; W1-03's `server/src/artifacts/` sniff is the product check and should be pointed at the same bytes when it lands.
- **Slot reason storage** for a written N/A reason is the reason text itself in `artifact_slot.reason` (the default N/A stores the D12 key); W1-04 owns the read mapping to the shared `NotApplicableReason` shape and may adjust it.
- **The denylist holds patterns, not names.** A list of real names or addresses would itself put real data into the repository; the reviewer's confirmation covers what a pattern cannot.

# Intent: content runner, claim grammar and ACC-METRIC-CITED (W4-06a, #221)

W4a QC reads only structured pack data. W4b makes QC read what the documents say. The extraction worker (W4-05b-d) already turns stored DOCX, XLSX and text-layer PDF bytes into text segments with text-free locators (W4-16). Nothing uses those segments yet.

This ticket adds the content runner that does: a second `QcRunner` implementation that executes only the catalogue's `content` rules, reads the bytes of the slots each rule may read, checks their hash, extracts them once per run through the `Extractor` port, parses claims with the provisional synthetic claim grammar (decision 10, WA-D09) and evaluates the first content rule, `ACC-METRIC-CITED`: a "Yes" on a hallucination or accuracy item must state an accepted metric, a value, a denominator, a threshold and its evidence. Each defective claim becomes its own finding, located by the claim's locator and `excerptHash` and keyed by a `claimKey` (decision 30), so two defects are two dispositions. No document text leaves the runner: message params are checked by pattern (`message_param_text`), and every citation must name an artifact of the same request (`evidence_outside_request`).

The runner scopes its reading by lane (decisions 22 and 28): an upload to slot 5 reads nothing, and a DPO or IT/Security approve attempt never reads slot 1, so a scanned slot 1 is an outage only for AI/COE, and no content finding is ever owned by another lane.

It is W4b ticket 12 (track T4, rules) and implements the [W4b plan](../../docs/engineering/implementation-plan-w4b.md) section 15 row W4-06a and sections 3.1-3.3 under the register rows "Ta's delegation (2026-09-27)" and "W4b delegated rulings (provisional)". The runner is not bound in any `QC_MODE` yet (W4-13b binds it), so no running desk changes behaviour. D07-D10 stay open; the grammar, the label lists and the rule are provisional until D09. Synthetic data only; no network call; no migration.

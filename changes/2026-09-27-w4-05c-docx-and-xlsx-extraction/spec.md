# Specification

Source: the W4-05c row of section 15 of the [W4b plan](../../docs/engineering/implementation-plan-w4b.md), section 4.3 (formats), section 4.4 (limits), decisions 8, 21 and 23, the unit layer of section 17, and the provisional [ADR-0006](../../adr/0006-qc-engine-and-extraction.md). The plan wins over issue #220. No spec amendment is assigned to W4-05c.

Done when:

1. **ZIP** (`worker/zip.ts`): reads the central directory as `sniff.ts` does (EOCD at the exact end, one disk, matching counts, no ZIP64, directory right before the EOCD, at most 2 000 entries, no duplicate or unsafe entry name, no encrypted entry, method stored or deflate only). Each part is read on demand: local header consistent with the central entry, data inside the file and before the directory, no two entries overlapping; deflate through `inflateRawSync` with `maxOutputLength`; output length equal to the declared size and CRC-32 equal to the declared CRC. A declared or actual part over 20 MiB, or a declared or actual total over 100 MiB, is `limit_bytes`; any other inconsistency is `unreadable`. A package the upload would refuse (a `vbaProject.bin`, a nested archive or executable) is `unreadable`.
2. **XML** (`worker/xml.ts`): strict UTF-8 (a UTF-8 BOM is dropped; invalid UTF-8 is `unreadable`); a tokenizer that yields open, close and text events with namespace-resolved names; `<!DOCTYPE` or any other `<!` declaration except comments and CDATA is `unreadable`; only `&lt; &gt; &amp; &quot; &apos;` and numeric references to valid XML characters are expanded, any other reference is `unreadable`; unbalanced or unterminated markup is `unreadable`.
3. **DOCX** (`worker/docx.ts`): reads `word/document.xml`. Every `w:p` gets the next 1-based ordinal, in document order; a paragraph's text is its `w:t` text, `w:tab` as a tab and `w:br`/`w:cr` as a line break; `mc:Fallback` content is skipped so an alternate rendering is not read twice. One segment per paragraph whose text is not blank, locator `{ kind: 'section', index }`. No `word/document.xml`, a DOCTYPE, a ZIP inconsistency or no text is `unreadable`.
4. **XLSX** (`worker/xlsx.ts`): sheet order from `xl/workbook.xml`; each sheet's part from `xl/_rels/workbook.xml.rels` (or `xl/worksheets/sheetN.xml` by position when the package has no workbook relationships); strings from `xl/sharedStrings.xml` (phonetic runs skipped) and inline strings; cell types `s`, `inlineStr`, `str`, `b`, `e`, `n`/absent and `d` read from the cached value (formulas are not evaluated). One segment per non-blank cell, locator `{ kind: 'cell', sheetIndex, cell }` with a 1-based sheet ordinal. A cell reference missing or outside `^[A-Z]{1,3}[1-9]\d{0,6}$`, a shared-string index out of range, a missing workbook or sheet part, or no text is `unreadable`, as are the DOCX conditions.
5. **Registry**: both media types registered in `FORMAT_EXTRACTORS`; PDF, PNG and JPEG stay unregistered (`unreadable`) until W4-05d.
6. **Wire**: the host's strict wire schema accepts the text-free ordinal locators `{ kind: 'section', index }` (integer at least 1) and `{ kind: 'cell', sheetIndex, cell }` (integer at least 1, A1 pattern), closed to extra keys; the port's `Locator` includes them until W4-16 adds them to the shared `EvidenceLocator`.
7. **Self-test**: `selfTest()` extracts an embedded synthetic DOCX and is true only when it yields the expected segment.
8. **Hostile set**: every row of the W0-08 hostile set (`artifacts/sniff.test-bytes.ts`), under the DOCX and the XLSX media type, ends as a clean reply, never a throw; every row the upload refuses ends as `ok: false`. The DOCTYPE, a zip bomb (declared and actual) and inconsistent ZIPs are `ok: false` through the real forked worker too.
9. The worker module-graph test stays green (`node:zlib`, `node:buffer` and `worker/` only). The extractor reads the W4-09a evaluation set's DOCX and XLSX renderings at the locators the labels expect (checked against the renderer's claim locators).

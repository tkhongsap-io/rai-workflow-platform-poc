## Deviations, defaults and limitations (for the reviewer)

- **PR size.** W0-02 section 11.1 proposed W1-03a (store and pipeline) and W1-03b (routes) as separate PRs; issue #19 is the single ticket the task brief assigns, so both halves are here. The commit is one because the routes are the only consumer of the pipeline and the Done-when needs both.
- **`limits.fields`.** W0-08 section 3 names `limits.fields: 0`. With that value `@fastify/multipart` skips the field, then cancels the request from a later tick and destroys a file stream it has already handed to the handler, which left the request hanging when a field preceded the file. The route registers `fields: 1, fieldSize: 0` and refuses any non-file first part itself, synchronously, before a byte is read (`422 invalid_input`); no field value is ever read (`fieldSize: 0` truncates it to nothing). Same outcome as the spec's intent ("no other field is read; the parser is not a JSON channel"), decided in the handler instead of the parser. A second file part trips `files: 1`; it is never stored.
- **`preservePath: true`** on the parser so `../escape.pdf` reaches the section 3 rule and is refused as `filename_invalid` (the spec: "path characters are refused rather than stripped so the uploader sees what was wrong"); without it busboy silently reduces the name to `escape.pdf`.
- **PDF token scan** matches whole name tokens (the token followed by whitespace, a delimiter or end of file), so `/JSX` is not `/JS`; this is the faithful reading of "tokens" and rejects nothing the spec would accept. A `/JS` inside an uncompressed stream still rejects, as the spec accepts for synthetic data.
- **Pack-total test attaches slots in the database.** The attaching save-draft is W1-04's route; the test writes `artifact_slot` rows directly (same table, same rule) to reach the 150 MiB boundary. W1-04's attach re-checks the same total per W0-08 check 10.
- **`upload.rejected` never logs the hash of rejected bytes** (W0-08 5.1 and the W0-10 3.3 field list); W0-06 8.4 mentions "hash of the rejected bytes" in passing, W0-10 owns the field list, so the registered fields win.
- **Audit refs**: the `artifact.uploaded` event carries `artifact_id`, `content_hash`, `size_bytes` and `deduplicated`; the media type is not a ref (the OOXML values exceed the 64-character reference rule) and the filename is never one (it may carry personal data); both are on the row by id.
- **Test seam in `app.ts`** (`logStream`): the integration suites assert on emitted log lines in-process. Absent, the logger writes to stdout exactly as before.
- **Shared schema typing fix** (`AllowedMediaTypeSchema`): a contract file, but no shape change; without it `ArtifactRef.mediaType` was `never` and the route could not return the 7.4 shape.
- **Browser suite red** on the W1-12 "route is absent" spec is pre-existing on `main` (W1-09 review) and belongs to W1-12/W1-01; untouched here.
- **`docs/board`**: not appended (the merge step appends it, as for W1-01 and W1-09); `DEVLOG.md` and `CHANGELOG.md` likewise.

# Design contract

One stateful prototype covers scoped owner/SPOC queue, nine-slot pack, three parallel reviewers, artifact-specific send-back, immutable prior versions, resubmission, human dispositions, qualified Ready, and versioned Admin configuration. True website-derived visual reference, synthetic data and explicit demo controls.

Done: visible artifact; observed end-to-end and role/config tests; responsive review and corrections; developer handoff with open decisions and honest limitations. No production code, real integrations, public sharing, team messages or source-spec changes.

## Change to `w1-int-substitute-absent.test.ts`

The batch acceptance said this test would pass unmodified. It cannot. Its scan control asserted that `w2-07-reviewer-workspace.substitute.spec.ts` and `w2-09-disposition.substitute.spec.ts` exist and that there are at least 4 substitute specs. This batch deletes exactly those files, so the control now asserts that the one remaining substitute spec exists. The test also gained one assertion: because a project-level `testIgnore` replaces the top-level one, every project that sets its own `testIgnore` must still ignore `*.substitute.spec.ts`. That assertion failed when the substitute pattern was dropped from the projects' list (1 fail, 4 pass), and it passes with the list as committed.
